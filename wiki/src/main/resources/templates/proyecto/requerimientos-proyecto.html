Requerimientos del Proyecto

En esta sección se detallan los requerimientos funcionales y no funcionales del sistema Arrienda Tu Finca. Estos requisitos definen qué debe hacer la plataforma y cómo debe comportarse para ofrecer una experiencia eficiente, segura y fácil de usar tanto para arrendadores como para arrendatarios.

Requerimientos Funcionales

  • Administración de Propiedades: Destinado a arrendadores: Permite crear, modificar y gestionar propiedades disponibles para alquilar.
  • Búsqueda Avanzada:Pensado para arrendatarios: Incluye una función de búsqueda con filtros por ubicación y características para encontrar propiedades fácilmente.
  • Gestión de Solicitudes de Arriendo: Disponible para ambos perfiles (arrendadores y arrendatarios): Facilita el envío, seguimiento y notificación de solicitudes de arriendo.
  • Pagos con Seguridad: Para arrendatarios: Sistema que permite realizar pagos de manera segura con validación automática.
  • Sistema de Valoraciones: Utilizable por todos los usuarios: Proporciona una herramienta para dejar comentarios y calificaciones sobre la experiencia del arriendo.

Requerimientos No Funcionales

  • Seguridad: Se debe garantizar la protección del sistema mediante mecanismos como autenticación, cifrado de la información y control de accesos no autorizados.
  • Escalabilidad: El sistema debe estar preparado para crecer y adaptarse al aumento de usuarios y operaciones sin afectar su rendimiento.
  • Disponibilidad: Es fundamental que el sistema esté operativo la mayor parte del tiempo posible y ofrezca tiempos de respuesta adecuados.
  • Usabilidad: La plataforma debe ser fácil de usar y comprensible para todo tipo de usuarios, facilitando la interacción.
  • Eficiencia:Se busca que los procesos sean ágiles y optimizados para reducir los tiempos de espera y brindar una mejor experiencia al usuario.
